什么是 EXIF 数据？

EXIF（可交换图像文件格式，Exchangeable Image File Format）是数码相机和智能手机在拍照时自动写入图像文件的隐藏信息块。除非经过专门清理，否则它会一直随照片文件传输。

EXIF 数据包含哪些内容？

  • 地理位置：GPS 纬度、经度、海拔高度及拍摄朝向。
  • 拍摄设备：相机或手机品牌、型号、镜头型号，有时还包含机身序列号。
  • 日期与时间：照片拍摄的精确时间及后期最后修改时间。
  • 拍摄参数：快门速度、光圈、ISO 感光度、焦距与闪光灯状态。
  • 软件信息：最后保存或导出该文件的应用程序或修图软件名称。
  • 内嵌缩略图：存储在文件内部的小尺寸预览图——如果照片曾被裁剪，内嵌缩略图有时仍保留着裁剪前的完整原始画面。

与 EXIF 并存的还有其他元数据容器：XMP 与 IPTC 用于记录图注、作者姓名和版权信息；而 C2PA 内容凭证则用于保存带有数字签名的生成与编辑历史（详见 什么是 C2PA？）。

为什么 EXIF 关系到个人隐私？

一张在家门口拍摄的照片若带有 GPS 数据，会直接告诉接收者您的家庭住址；拍摄日期与设备序列号则能将不同渠道发布的照片关联到同一人。无论是新闻工作者、二手闲置卖家还是日常社交分享者，都有必要在发图前检查并剥离这些隐藏信息。

如何查看 EXIF 数据？

在大多数电脑上，右键点击图片并打开“属性”或“显示简介”即可看到基础信息。若想获得最完整的视图，可将文件拖入 AiUntrace，它会一次性列出包括操作系统未显示的 C2PA/JUMBF 在内的所有元数据块。

如何彻底清除它？

逐个修改或删除已知标签很容易遗漏隐藏容器。AiUntrace 采用像素级重绘方案：将图像解码为纯像素后重新写出新文件，从而一次性丢弃所有元数据容器，并在输出前自动复检确认无残留。若仅关注定位信息，也可参阅 如何清除照片中的 GPS 地理位置。

常见问题

EXIF 数据本身是有害的吗？

不是。对于管理个人本地相册而言，EXIF 非常有助于按时间和地点整理照片。只有当您把原图文件分享给不需要知道这些细节的他人时，它才会带来隐私风险。

屏幕截图会有 EXIF 数据吗？

截图包含的元数据通常少得多，一般不含 GPS 定位，但仍可能记录屏幕分辨率、设备类型和截图时间。
