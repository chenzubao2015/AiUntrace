如何在 Windows 和 Mac 上清除照片 EXIF 数据

Windows 和 macOS 均无需安装额外软件即可移除部分照片元数据。以下是各系统内置工具的具体用法、局限性，以及跨平台通用的彻底清理方法。

Windows：通过文件属性删除个人信息

  1. 右键点击照片文件，选择“属性”。
  2. 切换到“详细信息”选项卡，点击底部的“删除属性和个人信息”。
  3. 选择“创建删除了所有可能属性的副本”，或手动勾选要从原文件中删除的属性，点击“确定”。

Windows 会删除其识别到的常规属性，但可能会遗漏它未显示的容器（如 C2PA JUMBF 数据块或部分 XMP 扩展段），敏感照片建议清理后复检。

Mac：在“预览”中移除位置信息

  1. 使用“预览（Preview）”应用打开照片。
  2. 在顶部菜单选择“工具” → “显示检查器”，切换到“信息（i）”标签页。
  3. 点击“GPS”子标签，然后点击底部的“移除位置信息”。
  4. 保存文件。

此操作仅删除 GPS 坐标，相机型号、拍摄时间戳及其他元数据仍保留在文件中。

Mac：从“照片”应用导出时排除位置

在 Mac“照片”应用中，选择“文件” → “导出” → “导出照片”，在导出选项中取消勾选“位置信息”。导出的副本将不含坐标，图库中的原图保持不变。

任意电脑：在浏览器中彻底清除全部元数据

  1. 打开 AiUntrace，拖入 1 张或最多 50 张照片。
  2. 查看每张文件隐藏的元数据详情。
  3. 点击“清除元数据”，然后单张下载或打包下载为 ZIP。

AiUntrace 会将图片重新编码为纯像素，因此无论是系统能显示的 EXIF 还是隐藏的 C2PA 容器都会被彻底剥离，且文件全程留在您的电脑本地。

命令行工具补充：如果您熟悉命令行且已安装 ExifTool，可使用 exiftool -all= photo.jpg 清除所有元数据（添加 -overwrite_original 参数可直接覆盖原文件）。

看看您的照片隐藏了什么信息。 AiUntrace 可在浏览器本地列出并清除所有元数据块。

常见问题

重命名或压缩照片能清除 EXIF 数据吗？

重命名不会清除任何元数据。压缩或另存为操作取决于具体软件的实现，操作后请务必通过扫描复检确认。

清除后的 EXIF 数据还能恢复吗？

不能。一旦从副本中剥离了元数据，就无法从该副本中还原。如果您自己需要保留拍摄记录，请妥善保存原图，仅分享清理后的副本。
